# Wedding Page Documentation

## Overview
This project is a wedding webpage dedicated to the celebration of Sushith and Anupriya. The webpage features a countdown timer to their wedding date, images of the couple, and a location section.

## Project Structure
The project consists of the following files and directories:

- **index.html**: The main HTML document for the wedding webpage.
- **styles.css**: Contains styles for the webpage, including animations and layout.
- **script.js**: Implements the countdown timer and interactive features.
- **images/**: Directory for storing sample images of Sushith and Anupriya.
- **README.md**: Documentation for the project.

## Features
- Countdown timer to August 23, 2026.
- Image gallery showcasing the couple.
- Location section with a link to the wedding venue.

## Setup Instructions
1. Clone the repository or download the project files.
2. Open the `index.html` file in a web browser to view the wedding webpage.
3. Customize the images in the `images` directory with personal photos of Sushith and Anupriya.
4. Modify the countdown date in `script.js` if necessary.

## Notes
- Ensure that all images are appropriately sized for optimal loading times.
- Feel free to enhance the styles in `styles.css` to match your wedding theme.
- Test the countdown functionality to ensure it works correctly as the wedding date approaches.
